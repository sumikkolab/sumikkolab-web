コンセプト

Sumikko Lab は、IT 管理者が行う確認・記録・レポート作成の作業を、製品ごとのツールで助ける発行元です。

共通の軸は、ログ・レポート・ポリシー・設定を確認・分析して、次の判断につなげる作業を助けることです。

SBOM を読み込み、OSS の脆弱性・ライセンスリスクを分類し、レビュー・承認・レポート作成を支援する Windows デスクトップツールです。

助け方: 設定・構成の情報(SBOM)を読み込み、脆弱性・ライセンスリスクを分類し、レビュー・承認・レポート作成につなげます。

Sumikko Lab

A publisher of tools that help IT administrators with checking, recording, and reporting, with a separate tool for each product.

Last updated: 2026-10-27

Concept

Sumikko Lab is a publisher of tools that help IT administrators with the work of checking, recording, and creating reports, with a separate tool for each product.

The common thread is helping people review and analyze logs, reports, policies, and settings, and carry the result into the next decision.

Products

Dependa

A Windows desktop tool that loads an SBOM, classifies OSS vulnerability and license risks, and supports review, approval, and report creation.

How it helps: reads configuration and composition information (SBOM), classifies vulnerability and license risks, and leads into review, approval, and reporting.

Product siteMicrosoft Store

SecureNavigator

An offline assessment tool that supports attack scenario analysis, reference checks against guidelines, organizing response candidates, and report generation.

How it helps: helps with attack scenario analysis, guideline reference checks, organizing response candidates, and report generation, offline.

Product siteMicrosoft Store

CA Log Viewer

Reads Conditional Access sign-in logs so you can check "the policy I thought I set" against the actual sign-in logs.

How it helps: reads Conditional Access sign-in logs and checks settings against the actual logs.

Product siteMicrosoft Store

DMARC Analysis Assistant

Analyzes DMARC aggregate reports and bounce emails on the local device only, and shows suspected spoofing, configuration problems, and forwarding-related results separately.

How it helps: analyzes DMARC aggregate reports and bounce emails and tells suspected spoofing, configuration problems, and forwarding apart.

Product siteMicrosoft Store

CA Policy Analyzer

A security tool that analyzes Microsoft Entra ID Conditional Access (CA) policies in a local environment. Import policy JSON to review a gap analysis and improvement suggestions.

How it helps: analyzes Conditional Access policy JSON and presents a gap analysis and improvement suggestions.
