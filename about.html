発行元について

Sumikko Lab は、IT 管理者が行う確認・記録・レポート作成の作業を、製品ごとのツールで助ける発行元です。

共通の軸は、ログ・レポート・ポリシー・設定を確認・分析して、次の判断につなげる作業を助けることです。

製品

  • Dependa: 製品サイト / Microsoft Store
  • SecureNavigator: 製品サイト / Microsoft Store
  • CA Log Viewer: 製品サイト / Microsoft Store
  • DMARC 分析支援ツール: 製品サイト / Microsoft Store
  • CA Policy Analyzer: 製品サイト

文章の方針

  • 状態・日付・バージョンは、出典のある範囲だけを書きます。
  • できることを具体的に示し、できないことも明記します。
  • 実績の数字は、出典のあるものだけを掲載します。
  • 検索順位や AI 回答での引用は、約束しません。

About Sumikko Lab

Sumikko Lab is a publisher of tools that help IT administrators with the work of checking, recording, and creating reports, with a separate tool for each product.

The common thread is helping people review and analyze logs, reports, policies, and settings, and carry the result into the next decision.

Products

  • Dependa: Product site / Microsoft Store
  • SecureNavigator: Product site / Microsoft Store
  • CA Log Viewer: Product site / Microsoft Store
  • DMARC Analysis Assistant: Product site / Microsoft Store
  • CA Policy Analyzer: Product site

Writing policy

  • Status, dates, and versions are written only as far as a source exists.
  • We state concretely what the tools can do, and we also state what they cannot do.
  • Performance figures are published only when a source exists.
  • Search rankings and citations in AI answers are not promised.
